# 安卓连点器

一个基于 Android 无障碍服务的基础连点器，参考 [ClickDevice Android](https://github.com/ming123aaa/clickdevice_android) 的点击与悬浮窗操作方式独立实现。

## 功能

- 在任意应用上方拖动目标点，确定点击位置。
- 通过悬浮按钮开始、停止点击；可拖动控制条，也可关闭悬浮窗。
- 设置点击间隔、按下时长和点击次数；次数为 0 时持续点击。
- 设置保存在本机；服务重新连接后恢复悬浮窗显示状态。

此版本聚焦单点连点。参考项目中的脚本录制、多点手势、分组和快捷键尚未实现。

## 构建与使用

需要 Android 10（API 29）或更高版本、JDK 17 或更高版本及 Android SDK 35。运行 `./gradlew :app:assembleDebug`，安装 `app/build/outputs/apk/debug/app-debug.apk`。

首次打开应用必须按顺序完成设置：先开启“连点器点击服务”无障碍权限，返回应用后才会解锁悬浮控制；再按提示授予“显示在其他应用上层”权限。未完成第一步时不能启动悬浮窗。圆形 Logo 悬浮球始终贴在屏幕左侧或右侧边缘，拖动到另一半屏幕时会切换到另一侧。

点击悬浮球先展开可拖动的工具栏，其中包含“连点器、录制脚本、敬请期待”。工具栏在竖屏下占屏幕宽度的 90% 并横向排列；横屏下使用较窄的固定宽度、占屏幕高度的 90%，每行显示一个“上方图标、下方文字”的工具并支持纵向滚动。点击“连点器”后工具栏收起，屏幕顶部显示可拖动的“开始、编辑、退出”控制条。“编辑”只修改点击间隔；点击“开始”会先弹出缓存的点击次数，可用 `±1` 调整，确认“执行点击”后才运行。点击“录制脚本”后，顶部操作栏初始为“开始、取消、完成”，录制中切换为“暂停、取消、完成”；完成后原地切换为“回放、取消、保存”，可先试播再决定是否保存。脚本列表回放时同样先显示顶部操作栏，用户切换到目标应用并点击“开始”后才倒计时执行。关闭无障碍服务会同时关闭悬浮控制。

点击操作使用系统 `AccessibilityService.dispatchGesture`；服务不读取界面内容或上传数据。悬浮窗使用 `TYPE_APPLICATION_OVERLAY` 和独立的“显示在其他应用上层”权限，由前台服务保持运行。Android 12 及以上版本在点击目标点处使用半透明窗口，以便手势传递给下层应用。
