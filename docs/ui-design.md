# 连点器界面设计说明

## 目标与范围

面向需要快速执行重复点击和管理自动化脚本的 Android 用户。本轮聚焦主控制台与现有脚本入口，保留快速连点、普通脚本、录制脚本、自定义流程和快捷按键五项核心能力。

## 视觉构思

界面采用“自动化控制台”结构。首屏先展示设备是否就绪，再提供快速连点；复杂能力收进稳定的工作台列表。橙红渐变来自应用新图标，暖白背景降低长时间使用的视觉压力，深色快速操作按钮形成明确的操作焦点。

## 布局与规则

- 目标视口：Android 竖屏，按 360–430dp 宽度适配，页面垂直滚动。
- 间距：以 4dp 为基础，主要页面边距 20dp，卡片圆角 18–24dp。
- 字体：系统无衬线字体；页面标题 23sp，模块标题 16–19sp，辅助文字 12–13sp。
- 主色：`#FF5138`；渐变：`#FF7A45 → #FF3D5A`；背景：`#FFF8F4`；正文：`#271916`。
- 触控区域：主要按钮至少 48dp，高频入口整行可点击。

## 内容变化

工作台使用 2×2 模块网格并显示当前条目数量，返回主页时刷新。无障碍服务与悬浮窗状态会改变文案和按钮颜色。模块说明控制为短句，确保 360dp 窄屏下仍保持一行两个且文字可读。

连点运行期间，目标点在每次手势分发时产生橙红色缩放脉冲；高速连点会形成连续心跳效果，帮助用户确认点击位置与执行状态。
